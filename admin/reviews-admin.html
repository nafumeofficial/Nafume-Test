NAFUME — Review Moderation

Customer reviews are saved as pending and are not shown on the storefront until approved here. Reviews are free text and photos written by strangers, so nothing is published automatically.
Only reviews tied to a real paid order can be submitted, and each is marked verified.
Access is by API token, held in this tab's sessionStorage and cleared when the tab closes. Set ADMIN_API_TOKEN to a long random value.
