NAFUME — Orders & Fulfilment

This page talks to the live order database through /api/admin/orders. Recording a delivery date here is what makes a post-delivery review request become due — the daily job at /api/jobs/review-requests picks up orders delivered more than the configured number of days ago.
Access is by API token. The token is held in this tab's sessionStorage and is cleared when you close the tab. It is never written to localStorage, never put in the URL, and never sent anywhere except this site's own /api/admin/* endpoints. Do not open this page on a shared device, and set ADMIN_API_TOKEN to a long random value.
